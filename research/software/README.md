# Software Repositories

Add pinned Git submodules here when the manuscript evaluates, documents, or depends on software maintained in another repository.
Register each submodule in `research/reproducibility/submodules.tsv` and cite the exact commit or archival release in the manuscript.
Keep paper-specific analysis code under `research/analysis/`.
