# Foundational Data

Store immutable, repository-authorized foundational inputs here.
Add every stored file to `research/data/manifest.tsv` with its origin, version, license or access condition, sensitivity classification, `sha256:<digest>` checksum, and concise description.
Do not edit these files in place.
