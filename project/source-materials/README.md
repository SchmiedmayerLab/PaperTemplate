# Local Source Materials

This ignored directory is an inbox for earlier drafts, coauthor files, decision letters, local exports, and other unstructured context that still needs review.
Nothing here is automatically citable or authoritative.

Move a verified citation asset to `research/literature/`.
Register a reproducibility input under `research/data/`, `research/analysis/`, or `research/software/` as appropriate.
Record verified venue requirements in `project/notes/01_venue_requirements.md` and licensed publisher files in `paper/venue/`.
Record durable decisions in `project/notes/03_decision_log.md` rather than relying on filenames or agent memory.
