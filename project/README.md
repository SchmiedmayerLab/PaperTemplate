# Project

This directory holds the human context needed to plan, review, and submit one paper.

- `notes/` records paper-specific facts, evidence decisions, author feedback, venue requirements, and submission state.
- `guides/` contains reusable procedures that apply across papers.
- `source-materials/` is an ignored inbox for unstructured local context that still needs review and classification.

Record a decision in `notes/` when it describes this manuscript.
Change a guide only when the lesson should alter future publication workflows.
Do not duplicate source evidence or manuscript prose here.
Promote verified literature, data, software, and reproducibility inputs into the corresponding `research/` folder.
