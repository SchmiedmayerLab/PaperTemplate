# Venue Files

Place official journal class files, bibliography styles, and example templates here only when their license permits local reuse.
Record the download page, retrieval date, version, and required manuscript changes in `project/notes/01_venue_requirements.md`.
Preserve the publisher's copyright and license with an SPDX header, a `.license` sidecar, or a narrow `REUSE.toml` annotation.
Do not label publisher files as MIT merely because they reside in this repository.
Keep section content outside this directory so venue changes do not fork the scientific text.
