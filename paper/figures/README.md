# Figures

Use `source/` for editable schematic sources and `generated/` for manuscript-ready exports.
Every generated export must be declared in `research/reproducibility/pipeline.json` with its inputs, exact command, environment, and manuscript location.

Generate every empirical figure from foundational data through tracked code.
Do not make manual changes to a generated export.
Regenerate the export from its source instead.

Keep labels readable at final publication size.
Use accessible colors.
Give each figure one scientific purpose and a caption that defines its sample, comparison, metric, uncertainty display, and bounded takeaway.
