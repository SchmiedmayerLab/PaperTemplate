\begin{abstract}
This document demonstrates the standalone preprint presentation supplied with the PaperTemplate repository.
The design uses a compact title block, a visible repository link, an integrated abstract, and restrained running elements.
It keeps figures and tables visually prominent while preserving a conventional single-column reading experience.
The accompanying repository separates manuscript content, evidence, computation, and venue adaptation so each layer remains reviewable.
\paperkeywordsblock
\end{abstract}

\paperstartmaintext

\section{Introduction}

A preprint should look deliberate without resembling a product brochure or a publisher imitation.
The default presentation therefore relies on editorial typography and measured spacing rather than institutional branding, mascots, or decorative panels.

The scientific text remains independent of the presentation layer.
Authors can retain this design for circulation and preprint release, then disable it when an official venue class controls the submitted manuscript.

% [schmiedmayer2026papertemplate; CITATION.cff and project/guides/reference-workflow.md]: identifies the software repository and its included source-first reference workflow.
The template source and its reference workflow are distributed together in the Paper Template software repository~\citep{schmiedmayer2026papertemplate}.

The manuscript prose, diagram, and table in this specimen are illustrative.
The document exists to make the visual system inspectable before it is used for a real paper.

\section{A restrained visual system}

\subsection{Typography and hierarchy}

XCharter carries the title, headings, body text, and captions so the manuscript retains a coherent scholarly voice.
Source Sans Pro is limited to metadata, running elements, and figure labels.
Dark ink carries the argument, muted gray handles secondary information, and Stanford cardinal is reserved for small navigational cues and links.

\subsection{Front matter that starts the paper}

The first page groups the title, authors, affiliations, correspondence address, repository, abstract, and keywords.
The main text begins on the following page.
Long author lists and venue-specific fields can move to an adapted title block without changing the manuscript sections.

\section{Reproducibility by default}

The repository links foundational inputs, versioned analysis, and publication artifacts.
Generated figures and tables declare their inputs and commands, while conceptual diagrams retain editable sources.

The workflow emphasizes three practical checks:

\begin{itemize}
  \item A clean clone rebuilds public artifacts.
  \item Every reported value has evidence or an explicit author action.
  \item Venue changes alter presentation without duplicating content.
\end{itemize}

\section{Adapting the template}

Presentation profiles control appearance, while article profiles determine scientific structure.
Venue adapters replace the class, front matter, and bibliography rules without duplicating manuscript content.
